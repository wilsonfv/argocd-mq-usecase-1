# argocd-mq-usecase-1

Dedicated cluster and Argo CD application configurations for GCP Project `mq-usecase-1`.

## Structure
- `argocd-control-plane/`: Dedicated configuration and values for Full Argo CD Control Plane (VPC1).
- `argocd-control-plane-headless/`: Dedicated configuration and values for Headless Argo CD Core Control Plane (VPC2).
